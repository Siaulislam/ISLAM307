# ISLAM307 Arabic Isnad Engine
#
# Narrators come ONLY from the Sanad (Isnad). Never from the Matn.
# Compiler is metadata of the collection — not a link in the rawi chain.
# Parallel ح markers produce separate sanads (never merged).
# Relative tokens (أبيه / أمه / …) are not stored as names; resolve from
# the previous narrator when the relationship is recoverable from that
# authenticated name (ibn/bin pattern). Never invent identities.
# Low-confidence parses go to the review queue; only approved sanads are
# production-ready.
