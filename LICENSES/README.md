# Dataset license registry

Every religious dataset must have one file in this directory and a matching
record in `app/assets/modules/dataset_registry.json`.

Release approval requires:

1. Official source and rightsholder identity.
2. Complete license/Terms URL or written permission.
3. Explicit permanent offline redistribution permission.
4. Explicit commercial distribution permission.
5. Version, download date, checksum and required attribution.

`approved_for_bundling` is prohibited when any item is missing. Pending records
are UI/database placeholders only and contain no religious text.
